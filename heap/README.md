# Куча

Задачи на двоичную кучу и её применения.

## A. Приоритетная очередь

Реализуйте очередь с приоритетами на основе максимальной двоичной кучи. Команда `0 x` добавляет число `x`, команда `1` извлекает и выводит текущий максимум.

### Входные данные

В первой строке задано число команд. Далее идут команды `0 x` и `1`.

### Выходные данные

Для каждой команды извлечения выведите максимальный элемент на отдельной строке.

### [Решение](A.py)

## B. Пирамидальная сортировка

### Входные данные

В первой строке задано число `N`, затем — `N` целых чисел.

### Выходные данные

Выведите последовательность в неубывающем порядке.

## C. Минимальная очередь с приоритетами

Поддерживайте пустую очередь с приоритетами. Команда `ADD x` добавляет число, `EXTRACT` извлекает минимальное число, а `CLEAR` очищает очередь. При извлечении из пустой очереди выведите `CANNOT`.

### [Решение](C.py)

## D. Максимальная очередь с приоритетами

Поддерживайте очередь с приоритетами с теми же командами `ADD`, `EXTRACT` и `CLEAR`, но команда `EXTRACT` должна извлекать максимальное число. При извлечении из пустой очереди выведите `CANNOT`.

## E. Соединение канатов

Даны длины канатов. За каждое соединение двух канатов взимается плата 5% от длины получившегося каната. Найдите минимальную суммарную стоимость соединения всех канатов.

### Входные данные

В первой строке задано число канатов `N`, во второй — их длины.

### Выходные данные

Выведите стоимость с двумя знаками после десятичной точки.

### [Решение](E.py)

## F. Одновременные интервалы

Для каждого интервала заданы время начала и продолжительность. Определите максимальное число интервалов, которые идут одновременно.

### Входные данные

В первой строке задано число интервалов. В следующих строках указаны время начала и продолжительность каждого интервала.

### Выходные данные

Выведите максимальное число одновременно идущих интервалов.
