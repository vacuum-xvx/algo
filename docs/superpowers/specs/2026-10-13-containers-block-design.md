# Блок «Контейнеры»: дизайн дополнения репозитория

## Цель

Дополнить репозиторий `vacuum-xvx/algo` решениями блока «Контейнеры» из
`Desktop.zip`, сохранив существующие решения без изменений и повторив принятую
в репозитории структуру учебных блоков.

## Объём

- Создать каталог `containers/`.
- Добавить в него авторские решения `A.py`–`H.py` из `Desktop.zip` без замены
  их кодом из эталонного репозитория.
- Добавить `containers/README.md` с условиями задач A–H и относительными
  ссылками на соответствующие решения.
- Добавить ссылку «Контейнеры» в корневой `README.md`.
- Не переносить задачу N и другие отсутствующие решения из эталонного
  репозитория.
- Не изменять существующие каталоги `sorting/` и `binary_search/`.

## Структура

```text
algo/
├── README.md
├── binary_search/
├── sorting/
└── containers/
    ├── README.md
    ├── A.py
    ├── B.py
    ├── C.py
    ├── D.py
    ├── E.py
    ├── F.py
    ├── G.py
    └── H.py
```

## Проверка

- Сверить контрольные суммы `A.py`–`H.py` с файлами внутри `Desktop.zip`.
- Проверить синтаксис всех восьми файлов через `python -m py_compile`.
- Выполнить краткие примеры ввода для каждой задачи.
- Проверить все относительные ссылки в двух README.
- Убедиться, что итоговый diff не затрагивает существующие решения.
