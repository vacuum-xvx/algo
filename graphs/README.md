## A. Матрица смежности простого графа

Определите, может ли матрица из нулей и единиц задавать простой неориентированный граф.

### Входные данные

Число вершин n, затем n строк матрицы по n чисел.

### Выходные данные

Выведите YES, если матрица симметрична и на диагонали стоят нули. Иначе выведите NO.

### Пример

**Входные данные**

```text
2
0 1
1 0
```

**Выходные данные**

```text
YES
```

## B. Истоки и стоки

Найдите вершины ориентированного графа без входящих рёбер (истоки) и без исходящих рёбер (стоки). Изолированная вершина входит в оба списка.

### Входные данные

Число вершин n и матрица смежности размера n × n. Единица в строке i и столбце j обозначает ребро из i в j.

### Выходные данные

Выведите количество истоков, затем их номера по одному на строке. Так же выведите количество и номера стоков. В каждом списке номера идут по возрастанию.

### Пример

**Входные данные**

```text
3
0 1 0
0 0 0
0 0 0
```

**Выходные данные**

```text
2
1
3
2
2
3
```

## E. Компоненты связности

Разбейте вершины неориентированного графа на компоненты связности.

### Входные данные

В первой строке заданы число вершин n и число рёбер m. Далее идут m пар концов рёбер. Вершины пронумерованы от 1 до n.

### Выходные данные

Выведите число компонент. Для каждой компоненты выведите её размер и на следующей строке номера входящих в неё вершин.

### Пример

**Входные данные**

```text
3 1
1 3
```

**Выходные данные**

```text
2
2
1 3
1
2
```

## H. Кратчайший путь

Найдите путь с наименьшим числом рёбер между двумя заданными вершинами.

### Входные данные

Число вершин n, матрица смежности размера n × n, затем номера начальной и конечной вершин. Нумерация начинается с 1.

### Выходные данные

Выведите длину кратчайшего пути или −1, если пути нет. При положительной длине на второй строке выведите вершины пути от начала до конца.

### Пример

**Входные данные**

```text
3
0 1 0
1 0 1
0 1 0
3 1
```

**Выходные данные**

```text
2
3 2 1
```

## I. Ход конём

Переведите шахматного коня между двумя клетками доски за минимальное число ходов. За ход одна координата меняется на две клетки, а другая на одну.

### Входные данные

Размер доски n × n задан числом n. Следующие две строки содержат координаты начальной и конечной клеток. Координаты отсчитываются от 1.

### Выходные данные

Выведите минимальное число ходов, затем координаты каждой клетки маршрута, включая начальную и конечную, по одной паре на строке.

### Пример

**Входные данные**

```text
5
1 1
2 3
```

**Выходные данные**

```text
1
1 1
2 3
```

### [Решение](I.py)

## J. Проверка топологической сортировки

Проверьте, располагается ли начало каждого ребра ориентированного графа раньше его конца в заданном порядке вершин.

### Входные данные

В первой строке заданы число вершин n и число рёбер m. Следующие m строк задают рёбра парами «начало конец». В последней строке дана перестановка вершин от 1 до n.

### Выходные данные

Выведите YES, если порядок подходит, иначе NO.

### Пример

**Входные данные**

```text
3 2
1 3
2 3
3 1 2
```

**Выходные данные**

```text
NO
```
